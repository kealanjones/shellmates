# QA Pipeline — Quality Validation Framework

## Required QA Check Categories
- Vision drift
- Couples-first design
- Relationship safety
- Mobile usability
- Asynchronous progression
- Story consistency
- Schema compliance
- Technical quality
- Performance
- Accessibility
- Tone drift
- Content duplication
- Build health

## QA Flow
1. Define milestone test strategy.
2. Build risk-based test matrix across categories.
3. Execute tests and log defects with reproducible steps.
4. Map defects to impacted quality gates.
5. Re-test after fixes and run regression.
6. Issue gate recommendation (pass/fail/conditional).

## Evidence Standard
- Repro steps, expected vs actual behaviour.
- Device/build context for mobile findings.
- Severity rationale tied to user impact and safety risk.
