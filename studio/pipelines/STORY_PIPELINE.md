# Story Pipeline — Chapter Creation

## Chapter Pipeline
1. Chapter concept.
2. Emotional theme definition.
3. Magical adventure framing.
4. My Path design.
5. Their Path design.
6. Optional support action design.
7. Our Tidegate design.
8. Shared resolution drafting.
9. Reward definition.
10. Memory object definition.
11. Relationship design review.
12. Narrative consistency review.
13. Mobile session review.

## Language Rules
- No blunt therapy framing.
- No shame-based gates.
- No “waiting for partner” language.
- Preferred magical language examples:
  - “The tide is gathering.”
  - “The bridge is listening.”
  - “The lantern is half-lit.”
  - “Your lobster is keeping watch.”
