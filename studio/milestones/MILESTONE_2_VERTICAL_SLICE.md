# Milestone 2 — Vertical Slice

## Goal
Deliver a polished representative slice proving product quality and production feasibility.

## Vertical Slice Scope
- Complete Cove loop.
- Complete asynchronous story chapter.
- One Player A path.
- One Player B path.
- One Tidegate.
- One lobster delivery interaction.
- One décor reward.
- One memory reward.
- Save/load.
- Mobile readability validation.

## QA Expectations
- Full quality gate review pass.
- Relationship safety and tone checks on chapter content.
- Async progression verification.
- Mobile performance/usability pass on target devices.

## Out of Scope
- Backend production integration.
- Account pairing services.
- Analytics/monetisation rollout.
- Large seasonal content packs.

## Acceptance Criteria
- Slice demonstrates core fantasy and north star.
- Chapter flow includes My Path, Their Path, Tidegate, shared resolution.
- Rewards integrate correctly into Cove and memory systems.
- Build health is stable for repeated session testing.
