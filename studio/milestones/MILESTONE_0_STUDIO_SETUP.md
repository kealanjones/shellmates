# Milestone 0 — Studio Setup

## Goal
Establish a complete, enforceable studio operating system before any game implementation work.

## Scope
- Strengthen AGENTS operating manual.
- Deepen all bibles, departments, schemas, pipelines, and review gates.
- Define practical milestone sequence (M1 and M2).
- Seed decision log with foundational product decisions.

## Out of Scope
- Game code.
- Art asset production.
- Backend/account systems.
- Large content generation.

## Acceptance Criteria
- AGENTS.md exists and is strong.
- Studio bibles exist and are practical.
- Departments and roles exist with decision boundaries.
- Ask-when-unsure rules exist as clear matrix.
- Quality gates exist and are reviewable.
- Milestones exist with explicit next-phase scope.
- Decision log exists with initial decisions.
- No game code exists.
- No backend exists.
- No large content batches exist.

## Review Checklist
- Vision alignment confirmed.
- Couples-first safeguards present.
- Mobile-first direction explicit.
- Async progression standards clear.
- Deferred systems explicitly listed.

## Risks
- Overly abstract docs that cannot guide execution.
- Premature decisions that lock future architecture.
- Safety rules interpreted inconsistently.

## Completion Definition
Milestone 0 is complete only when documentation is actionable for future agents and all listed acceptance criteria are met without scope leakage into implementation.
