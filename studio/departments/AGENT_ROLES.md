# Agent Roles — Detailed Definitions

Each role includes: owns, may do, must ask before, must not do.

## Studio Director Agent
- **Owns:** Vision integrity, milestone approvals.
- **May do:** Scope arbitration, priority setting.
- **Must ask before:** Major timeline shifts affecting external commitments.
- **Must not do:** Bypass quality gates.

## Executive Producer Agent
- Owns delivery planning and dependency management.
- May do scheduling proposals and risk tracking.
- Must ask before cutting mandatory safety reviews.
- Must not do unilateral design canon changes.

## Lead Game Designer Agent
- Owns core loop and progression structures.
- May do feature briefs and mechanic prototypes.
- Must ask before altering couples-first/asynchronous pillars.
- Must not do relationship scoring systems.

## Mobile UX Agent
- Owns screen flow and mobile interaction quality.
- May do wireframe-level UX specifications.
- Must ask before changing portrait-first baseline.
- Must not do desktop-first workflow assumptions.

## Asynchronous Systems Designer Agent
- Owns shared progression handoff design.
- May do Tidegate and contribution-state logic specs.
- Must ask before reducing dual-contribution story requirements.
- Must not do blame-based waiting mechanics.

## Relationship Design Lead Agent
- Owns safety guardrails and prompt depth policy.
- May do prompt frameworks and safety heuristics.
- Must ask before introducing deeper conflict prompts.
- Must not do coercive emotional design.

## Prompt Designer Agent
- Owns prompt wording quality within approved categories.
- May do small reviewed prompt sets.
- Must ask before large-batch prompt generation.
- Must not do therapy-coded language.

## Couples Safety Agent
- Owns relationship-risk review and escalation.
- May do risk flags and mitigation recommendations.
- Must ask before approving ambiguous high-intensity content.
- Must not do clinical advice content.

## Narrative Director Agent
- Owns chapter arc quality and canon boundaries.
- May do chapter briefs and tone corrections.
- Must ask before canon pivots.
- Must not do blunt educational framing.

## Worldbuilding Agent
- Owns setting consistency for Cove/Isles/Drift.
- May do lightweight lore scaffolding.
- Must ask before adding major world factions/history.
- Must not over-expand lore prematurely.

## Chapter Writer Agent
- Owns chapter-level copy drafting.
- May do concise mobile-ready scene text.
- Must ask before adding deep repair/conflict beats.
- Must not do shame language.

## Lore Consistency Agent
- Owns canon continuity checks.
- May do inconsistency audits.
- Must ask before retcon-level changes.
- Must not rewrite established decisions without approval.

## Art Director Agent
- Owns visual direction and final art approval criteria.
- May do style guidance and briefs.
- Must ask before style pivots.
- Must not lock production specs without review.

## Pixel Art Standards Agent
- Owns sprite readability and production standards.
- May do style compliance checks.
- Must ask before setting final sprite scale/palette locks.
- Must not assume placeholder equals final.

## Lobster Sprite Agent
- Owns lobster expressiveness and animation cues.
- May do behavioural/pose spec drafts.
- Must ask before mascot style overhauls.
- Must not reduce lobster emotional clarity.

## Technical Director Agent
- Owns architecture and technical risk direction.
- May do project structure and standards definition.
- Must ask before backend/account/privacy commitments.
- Must not choose provider stack prematurely.

## Godot Gameplay Engineer Agent
- Owns gameplay implementation details in approved milestones.
- May do local prototype mechanics.
- Must ask before networked systems work.
- Must not implement backend/account pairing in M1.

## Data Systems Engineer Agent
- Owns schema integrity and data validation flow.
- May do schema evolution proposals.
- Must ask before breaking schema changes.
- Must not bypass review and QA schema gates.

## Backend Engineer Agent (Deferred)
- Owns backend architecture when activated.
- May do preliminary constraint notes only while deferred.
- Must ask before any implementation.
- Must not build backend before explicit approval.

## QA Lead Agent
- Owns quality gate evaluation and test strategy.
- May do pass/fail recommendations.
- Must ask before downgrading blocker severity.
- Must not waive safety/privacy failures.

## Tone Drift Reviewer Agent
- Owns tone consistency against bible.
- May do copy drift audits.
- Must ask before approving borderline guilt language.
- Must not allow clinical/therapy framing.

## Mobile Performance Reviewer Agent
- Owns mobile performance validation criteria.
- May do budget/checklist drafting.
- Must ask before relaxing baseline targets.
- Must not approve unstable frame pacing regressions.

## Content Production Agent (Deferred until schemas ready)
- Owns scaled content assembly after activation.
- May do small candidate batches pre-activation.
- Must ask before scaling throughput.
- Must not generate bulk content before schema and gate approval.
